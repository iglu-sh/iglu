## What iglu is
**Iglu** is an automation suite for the [nix](https://nixos.org) ecosystem. It has the following components:
- Cache: Caching of derivations.
- Builder: Build derivations based on flakes via API or scheduler.
- Controller: Web interface to manage builder and cache (not implemented yet).


## Features:
- ✅: supported
- 🚧: work in progress
- ❌: not supported
- 📅: planned

|Feature|Component|Status|Description|
|---|---|---|---|
|[cachix](https://cachix.org) compatible|Cache|🚧|Supports the cachix client to push new derivations|
|multi tenant|Cache|✅|Every instance can manage multiple caches|
|deduplication|Cache|✅|Derivations get deduplicated over every tenant|
|container|Cache<br/>Builder|✅|Deployable via docker/podman|
|nix module|Cache<br/>Builder|✅<br/>📅|Ready to use nix module|
|S3|Cache|✅|Store your derivations in an S3 bucket|
|local storage|Cache|✅|Store your derivations local on a disk|
|Cloudflare workers|Cache|📅|Run the cache completely via Cloudflare Workers|
|Web-controller|Controller|📅|A Web-App that can manage the cache and builders|
