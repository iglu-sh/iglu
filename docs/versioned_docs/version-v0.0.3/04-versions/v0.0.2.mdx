## Features
### Cache
- Derivation Upload by a cachix client
- Cachix Deploy Feature
- Basic Nix Derivation retrieval by a Nix client
- Server Side or Client Side signing of derivations
- Typescript SDK and Rest API for interacting with the Cache Service
- S3 or local storage file backend for serving derivations
- Postgres or SQLite Support
- Deploy as Container or Nix Service

### Builder
- Basic Nix Derivation Builder implementation
