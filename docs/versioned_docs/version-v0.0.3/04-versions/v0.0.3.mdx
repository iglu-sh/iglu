## Original GitHub Release
This release addresses the first batch of severe security issues that Iglu has (Severity: High in BUGS.md), it also includes small improvements to the Iglu builder, the documentation got reworked and we now have a CONTRIBUTING.md and AGENTS.md file with an AI Coding policy.
