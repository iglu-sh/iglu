Hey there! If you're looking to update your iglu cache you've come to the right place. A version update usually should not require you to
have to do anything. Sometimes Iglu does require more involvement on major updates this is usually while jumping from one major version to another.  

See below for all supported versions and if there's an upgrade guide available for it.
## Support policy
We support the latest major version and all minor versions or patches in that major version window. We do not backport anything to past major versions, except for very critical security fixes.

## Versions

:::warning

Iglu is currently in heavy development and we do not currently "support" any version after they are released. Releases are tested before going out and they are expected to work 
in a vacuum but they may contain bugs and unfinished features. We do not plan on porting back any security fixes to any version in the v0.x.x phase except in extraordinary circumstances. 

If you do encounter any issues please, please, PLEASE report them to us at https://github.com/iglu-sh/iglu/issues

:::

Currently supported Major Versions: None until v1.0.0
