## Iglu Cache
We are happy to announce the **Iglu-Cache**!
The cache is the first compoenent which is near production state! It is mostly **cacix** compatible and has builtin deduplication.
Each cache instance can host multiple tenants (caches).
Additionally you can choose from two storage backends and two databases.

### Databases
Iglu-Cache supports two database types
- [PostgreSQL](https://www.postgresql.org/) for larger deployments
- [SQLite](https://www.sqlite.org/) for lightweigt or test environments

and [Cloudflare D1](https://www.cloudflare.com/products/d1/) is planned.

### Storage
To make the storage as flexible as possible we provide two storage backends
- Filesystem to store the data directly on the hosts machine
- S3 to make the storage more scalable for bigger environments

### Deployment
The deployment could be done via [Docker](https://www.docker.com/) or a [NixOS](https://nixos.org/)-Module.
How to start is descriped [here](../docs/cache/getting-started)
